# Dynamic E-Library Management System (Full-Stack)

A responsive, secure Full-Stack web application developed to simulate an academic E-Library platform. The system empowers users to register, authenticating identities via dynamic frontend/backend checks, browse library catalogs, and execute core borrowing actions.

## 🚀 Key Architectures & Features

- **Responsive Frontend:** Clean design utilizing semantic HTML5 and CSS3 structures modeled with university design principles.
- **Client-Side Validation:** Real-time form evaluation via JavaScript (evaluating pattern complexity, input nulls, and mismatch faults).
- **Secure Authentication & Session Controls:** State persistence across pages using PHP native sessions and redirect safeguards.
- **Database Engine (MySQL):** Multi-table schema design mapping platform users, book records, and active transactional borrows.
- **Full CRUD Support:** 
  - *Create:* Registration handling via account parsing.
  - *Read:* Live catalog indexing using dynamic SQL wildcard string searching.
  - *Update:* Profile management for profile modifications.
  - *Delete:* Book restoration processing upon return triggers.

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3 (Custom modular variables), JavaScript (Vanilla ES6)
- **Backend Environment:** PHP Core Engine
- **Database Architecture:** MySQL Relational Database
- **Server Deployment:** Apache HTTP Server
